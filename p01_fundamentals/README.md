# Practical 01: C++ Fundamentals

Uses data types, constants, variables, arithmetic/relational/logical operators and cin/cout to find the total, percentage and grade of a student. Marks are checked, so wrong input shows an error.

## Files
- `input_invalid.txt`
- `input_valid.txt`
- `main.cpp`
- `output.txt`
- `output_invalid_input.txt`

Valid input and invalid input (letters instead of a mark).

## Compile and run
```bash
g++ -o app main.cpp
./app < input_valid.txt
```

## Output
See `output.txt` and `output_invalid_input.txt`.
